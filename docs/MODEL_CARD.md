# MiniGPT v4.2 模型说明

## 结构与用途

完成第二轮 RSFT/PPO，并提供第二轮配对及绝对质量评估工具。延续 v4 的 best-of-N、奖励模型与完整后训练链。

用于中文诗歌续写、字符级语言模型和训练流程学习。不是指令跟随助手；数据含古诗文和历史注释，输出质量受训练规模限制。

## 发行权重

默认 checkpoints/best.pt 是第二轮 PPO 的原样副本（文件名不代表独立质量最优）。pre_posttraining_baseline.pt 保留原预训练基线；另保留首轮/第二轮 RSFT、PPO 与奖励模型。

## 数据

保留 raw、预训练数据、两轮任务/候选/标注/准备数据及已付费评估标签，可复用离线缓存。第二轮 PPO 尚无独立人工质量优于 RSFT 的证据。

词表 ID 必须与权重保持绑定，不要跨版本替换同名文件。预训练数据只划分 train/val，没有独立 test；后训练任务另有隔离的 train/val/test。不同数据版本上的 loss 不宜直接比较。

## 质量解释

随包的历史指标仅说明对应历史运行；本次整理没有进行完整重训。硬诗体约束仅保证字数/标点；API 偏好、奖励分数和训练 loss 均不能代替人工诗歌质量判断。v4 的首轮 RM 准入阈值是在观察验证结果后调整的 0.64，只能视作实验门槛。

本次 CPU 冒烟验证不代表 CUDA 数值一致、GPU 吞吐或完整训练已经验收。
